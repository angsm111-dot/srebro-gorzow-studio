# Instrukcje

Rozmawiaj po polsku. Przeczytaj README.md, STUDIO-2.md, docs/CONTEXT.md i VALIDATION.md.
Repozytorium zawiera wyłącznie najnowsze Studio 2, zgodnie z poleceniem użytkownika. Nie przywracaj galerii ani dawnych projektów.
Preferencje: srebrzyste szarości, grafitowy tekst i jasna mięta; bez niebieskich, czerwonych, bordowych i czarnych paneli. Zachowaj podstrony, menu mobilne i wycenę w pamięci.
Node >=20; npm start i npm test; brak zależności do instalacji. dist/ to kod źródłowy. index.html i studio.html są wejściami tej samej strony; aktualizuj je razem.
Dane są demonstracyjne. Formularz niczego nie wysyła. Nie zapisuj sekretów. Przy publikacji Sites użyj istniejącego identyfikatora .openai/hosting.json.
