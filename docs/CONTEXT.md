# Aktualny kontekst

Strona skupu srebra w Gorzowie dla skupsrebragorzow.pl. Użytkownik wybrał Studio 2 / Silver Studio, a następnie polecił pozostawić na GitHubie tylko najnowszą wersję i usunąć starsze.

Najnowsze źródła znajdowały się w studio-2.zip. Są teraz bezpośrednio w dist/. Nie ma galerii projektów ani dawnych makiet.

Wygląd: srebrzyste szarości, grafitowy tekst, jasna mięta. Osobne podstrony, kalkulatory monet/sztabek/złomu, wspólna wycena, cennik, wykres 7/30/90 dni, FAQ, kontakt i lokalne przygotowanie zapytania. Stan wyceny trwa do odświeżenia.

Stawka 3 PLN/g, symulowany wykres, fikcyjny kontakt i grafika AI pozostają demonstracyjne. Formularz nie wysyła danych. Nie podłączono domeny. GitHub nie aktualizuje automatycznie projektu Sites.
